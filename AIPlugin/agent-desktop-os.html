AI 代理人桌面 App：新一代作業系統之爭

當 AI 代理人能寫程式、讀 Gmail、把策略文件推到 Notion，你打開電腦看到的第一個畫面，會不會就是它？

什麼是「代理人桌面 App」？

一個專門用來管理 AI 代理人的工作介面（Agent Management Interface），能跨應用讀取與操作資料，讓你在單一桌面上完成所有知識工作。它不只是聊天機器人，而是能自主拆解任務、存取你的 Gmail / Slack / Notion 等工具的全能工作平台。

GPT-5 時代，OpenAI 將 Codex 定位為資深工程師的 pair programming 工具，一般人在 ChatGPT 做 vibe coding 就好。但 Anthropic 率先證明了一件事：一個夠快、夠聰明、有情商、能存取電腦的模型，對程式設計師是極佳體驗；而既然它能自己寫軟體，就能做任何形式的知識工作。 Claude Code 從工程師工具長成跨職能代理人，迫使 OpenAI 對 Codex 做「硬轉向」——從只給工程師，變成寫作、招募、跑營運都能用的桌面 App。

轉折點：GPT-5.5 的發布

Every 成長主管 Austin 曾在 CLI 裡花週末連續 12 小時把 Claude Code 接到所有工具，那是他的「Agent Pill Moment」。但 GPT-5.5 發布後，他發現模型已與 Anthropic 打平，而 Codex 桌面 App 的速度、子代理品質、自動化推送的順暢度，是 Anthropic 桌面版目前還沒追上的細節。Austin 表示他現在 80% 的工作時間都在 Codex 裡。

希普補充了一個關鍵觀察：兩家公司看到同一個終局，未來一兩年會像賽馬一樣每隔幾週輪流領先。但等生態真的長出來，你選定的代理人桌面 App，會像 10 年前選 iOS 還是 Android 那樣，把你綁進整個工作生態。

⚙️ 六大工作流精華：兩條最反直覺的實踐

1

讓代理人告訴你工具該怎麼用

Austin 開新對話時不是下指令，而是反問 Codex：「請看看我最常用 Notion、Slack、Gmail 做什麼，建議幾個自動化。」Codex 會回提「跟進雷達」「事件指揮中心」「招募追蹤」等選項。

這顛覆了十年的 SaaS 邏輯：以前是「我有目的、工具幫我達成」；現在是「我有原料、模型告訴我能做什麼」。

2

KPI 儀表板：3% 誤差讓下游全歪

Austin 要 Codex 建 Notion KPI 表，發現 5-10% 的誤差率不可接受。他的原則：只要源頭資料有 3% 誤差，整個代理人鏈下游的決策都會歪掉。誤差在代理人鏈條中是複合放大，不是線性增加。

3

把工作環境變成資料夾

將所有專案、文件、對話組織成結構化的資料夾系統，讓代理人能自動定位和引用正確的上下文資訊。

4

代理人寫草稿、人類完稿

用語音 App Monologue 口述思考，交給 Codex 整理成文件，自己只負責確認每個重點是否站得住。規矩是：文件中被問到細節不能說「不知道有寫這個」。

5

GTM 計畫五分鐘出底稿

Go-to-Market 計畫從構思到底稿只需五分鐘。COO 收到後第一個動作不是讀，而是叫自己的代理人摘要、抽商業案、列負責章節。

6

招募變成大海撈針

利用代理人自動從多個來源篩選人才，建立候選人追蹤流程，大幅加速招募效率。

⚠️ 代理人鏈的「誤差級聯」風險

當多個代理人串聯運作時，源頭的微小誤差會逐層複合放大

📊 讀取 POS 資料

第二層代理人
🧪 設計新品菜單
誤判「市場愛重甜」

🔮 三大關鍵趨勢

🖥️

趨勢一：代理人重定義「打開電腦做什麼」

過去十年知識工作的入口是瀏覽器與 SaaS 儀表板，未來十年的入口很可能是一個能看到、能點、能跨 App 操作的代理人桌面。誰先把這個 surface 設計成最順手的版本，就拿下未來通用作業系統級別的話語權。

🔀

趨勢二：工具切換速度以「季」為單位

Austin 從 Claude Code 全面搬到 Codex 只用了三個月。「選定一家供應商一路走到底」的策略風險變高，團隊都該保留每季至少一天的「玩工具時間」。Every 自己每年辦兩次「Think Week」，整週停掉日常工作只為了學新東西。

📝

趨勢三：文件設計要為代理人讀者服務

CEO 的代理人怎麼解析你的文件，比文字優美度更重要。Markdown、清晰章節、明確 Bullet Point、可被機器引用的段落結構，會從「工程師的偏好」變成「跨部門通用標準」。文件的可被代理人解析能力（Agent-Readability），開始成為新的競爭力。

工具與工作流變得太快，光跟著現在的工作方式跑，會被用新工具新範式的人靠預設值打敗。

— 丹．希普（Dan Shipper），直播尾聲
📋

Every 的代理人規則設計

為了避免 AI 幻覺「翻車」，Every 在 Codex 專案檔裡設了關鍵規則：「不要自己加沒在別處出現過的內容」、「想到新建議丟到 chat 就好，不要塞進文件」。這把 AI 從「會幻想的助理」拉回「會整理的祕書」。團隊規矩是：你交出的代理人寫的文件，會議上有人問細節不能說「我不知道有寫這個」，被抓包就完了。

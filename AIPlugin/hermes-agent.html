🌟 基本介紹與核心功能

什麼是 Hermes Agent？

Hermes Agent 是 2026 年 2 月由 Nous Research 發布的開源 AI 代理。與一般 AI 聊天機器人不同的是，Hermes Agent 具備持久記憶（跨對話記住你的偏好與專案脈絡）、自動技能學習（從使用經驗中自動建立可重用的工作流程），以及本機自動化能力（直接操作你的電腦進行檔案管理、瀏覽器自動化等任務）。

🪟 Windows WSL2 安裝教學

為什麼需要 WSL2？

Hermes Agent 目前原生支援 Linux 和 macOS 環境。在 Windows 上，最穩定的執行方式是透過 WSL2（Windows Subsystem for Linux 2），它可以在 Windows 內建立一個完整的 Linux 環境，效能接近原生 Linux。WSL2 從 Windows 10 版本 2004 (Build 19041) 起內建支援，Windows 11 則原生支援。

步驟一：確認系統需求

  • Windows 10 版本 2004 (Build 19041) 以上，或 Windows 11
  • 電腦需支援虛擬化技術（大多數現代電腦皆支援）
  • 建議至少 8GB RAM 與 20GB 可用磁碟空間

步驟二：以系統管理員身分開啟 PowerShell

在開始功能表搜尋「PowerShell」，右鍵選擇「以系統管理員身分執行」。

步驟三：安裝 WSL2

在 PowerShell 中輸入以下指令（Windows 10 build 19041+ 和 Windows 11 皆適用）：

PowerShell（系統管理員）
wsl --install

此指令會自動啟用必要的 Windows 功能、下載並安裝最新的 Linux 核心，以及預設安裝 Ubuntu 發行版。安裝完成後需要重新啟動電腦。

步驟四：設定 Linux 使用者帳號

重新開機後，Ubuntu 會自動啟動並要求你建立使用者帳號和密碼。這個密碼用於 Linux 環境中的管理員操作（sudo）。

WSL2 Ubuntu 終端機
# 系統會提示輸入新的使用者名稱和密碼 Enter new UNIX username: your_name New password: ********

步驟五：更新系統套件

WSL2 Ubuntu 終端機
sudo apt update && sudo apt upgrade -y
💡

之後要開啟 WSL2，可以直接在開始功能表搜尋「Ubuntu」，或在 PowerShell / CMD 中輸入 wsl 指令。Windows Terminal 應用程式也會自動偵測並新增 Ubuntu 標籤頁。

（選用）步驟六：啟用 GPU 加速

如果你的電腦有 NVIDIA 顯示卡，WSL2 自核心 5.10.43 起原生支援 GPU 穿透。只需確保 Windows 端已安裝最新的 NVIDIA 驅動程式即可（不要在 WSL 內額外安裝 Linux 版 NVIDIA 驅動）：

WSL2 Ubuntu 終端機
# 確認 WSL2 內能看到 GPU nvidia-smi
⚠️

若使用免費 API（如 Google AI Studio），不需要本機 GPU。GPU 加速主要用於搭配 Ollama 等本機模型服務時，才能獲得更好的推理速度。

步驟七：Windows 與 WSL2 檔案互通（重要）

在使用 Hermes Agent 時，你可能會需要讓它讀取 Windows 本機的檔案，或是從 Windows 存取它產生的資料。Windows 與 WSL2 之間的檔案互通非常簡單：

1. 從 Windows 存取 WSL2 的檔案

打開 Windows 檔案總管，在上方網址列輸入以下路徑，即可直接存取 WSL2 內的檔案系統：

\\wsl$ 或 \\wsl.localhost

例如，你在 WSL2 (Ubuntu) 中的家目錄預設路徑為：
\\wsl$\Ubuntu\home\你的WSL使用者名稱\

若要查看 Hermes Agent 的設定檔（預設在 ~/.hermes/），可以直接在 Windows 檔案總管中進入該資料夾查看或編輯。

2. 從 WSL2 存取 Windows 磁碟槽與檔案

在 WSL2 內，Windows 的磁碟槽（如 C槽、D槽）會自動掛載到 /mnt/ 目錄底下。對應關係如下：

  • C 槽根目錄對應為：/mnt/c/
  • D 槽根目錄對應為：/mnt/d/
  • Windows 桌面通常是：/mnt/c/Users/你的Windows使用者名稱/Desktop/
  • Windows 下載資料夾通常是：/mnt/c/Users/你的Windows使用者名稱/Downloads/

當你在 Hermes Agent 中下指令處理 Windows 上的檔案時，請記得提供上述的 /mnt/... 格式路徑。例如：「幫我讀取 /mnt/c/Users/ASUS/Desktop/文件.pdf 並摘要重點」。

📦 安裝 Hermes Agent

一鍵安裝（推薦）

Hermes Agent 提供自動安裝腳本，會自動處理所有相依套件（Python、Node.js、ripgrep、ffmpeg 等），不需要手動安裝任何前置軟體。

方法一：WSL2 內直接安裝（最簡單）

開啟 WSL2 終端機（Ubuntu），直接執行：

WSL2 Ubuntu 終端機
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

安裝程式會自動完成以下工作：

  • 安裝所有相依套件（Python、Node.js、ripgrep、ffmpeg 等）
  • 克隆 Hermes Agent 程式碼
  • 建立 Python 虛擬環境
  • 設定全域 hermes 指令
  • 引導你設定 LLM 提供者（API 金鑰）

方法二：Docker 方式安裝

如果你偏好容器化部署，可以使用官方 Docker 映像：

WSL2 Ubuntu 終端機
# 先安裝 Docker（如尚未安裝） sudo apt install -y docker.io sudo usermod -aG docker $USER # 拉取並啟動 Hermes Agent docker run -it --name hermes \ -v ~/.hermes:/root/.hermes \ nousresearch/hermes-agent

確認安裝成功

WSL2 Ubuntu 終端機
# 查看版本資訊 hermes --version # 查看可用指令 hermes --help
💡

安裝完成後，你可以隨時在 WSL2 終端機中輸入 hermes 來啟動代理。設定檔與記憶資料預設存放在 ~/.hermes/ 目錄中。

（選用）安裝 Web UI 圖形介面

如果你不習慣使用終端機，可以安裝 Hermes Web UI 來獲得類似 ChatGPT 的圖形化網頁對話介面。請在 WSL2 終端機中執行以下指令：

WSL2 Ubuntu 終端機
git clone https://github.com/nesquena/hermes-webui.git hermes-webui cd hermes-webui ./start.sh
⚠️

重要網址連線問題：
啟動腳本完成後，畫面上可能會顯示 Starting Hermes Web UI on http://127.0.0.1:8787。
請不要使用這個 127.0.0.1 的網址，因為會遇到無法送出訊息或無法儲存設定的問題。
請務必將網址改為 http://localhost:8787 進入，才能正確送出招呼用語並讓 AI 正常回應與儲存設定。

🔑 免費 API 金鑰申請

選擇 LLM 提供者

Hermes Agent 需要連接一個大型語言模型（LLM）作為推理引擎。你可以使用雲端 API（免費或付費）或完全離線的本機模型。以下介紹幾個免費方案：

提供者 免費模型 限制 適合用途
Google AI Studio Gemini 2.5 Flash 15 RPM / 1,500 RPD 一般對話、輕量代理任務
Ollama（本機） 任意開源模型 受限於硬體規格 完全離線、隱私至上
OpenRouter 多款免費模型 依模型而異 試用多種模型

方案 A：Google AI Studio（推薦入門）

  1. 前往 Google AI Studio 網站 (aistudio.google.com)
  2. 使用 Google 帳號登入
  3. 點選左側選單的「Get API key」→「Create API key」
  4. 選擇一個 Google Cloud 專案（或建立新專案），點擊「Create API key in existing project」
  5. 複製產生的 API 金鑰

取得金鑰後，在 Hermes Agent 中設定：

WSL2 Ubuntu 終端機
# 方法一：直接寫入環境設定檔 echo 'GOOGLE_API_KEY=你的API金鑰' >> ~/.hermes/.env # 方法二：使用互動式設定 hermes model
⚠️

Google AI Studio 免費方案的每日請求上限（1,500 RPD）在密集使用代理功能時可能較快用完，因為工具呼叫、重試、壓縮等操作會產生多次模型請求。建議日常使用注意用量，或考慮啟用 Google Cloud 計費方案以獲得更高額度。

方案 B：Ollama 本機模型（完全免費、無限制）

如果你的電腦有足夠的 RAM（建議 16GB 以上），可以使用 Ollama 在本機運行開源模型，完全不需要任何 API 金鑰：

WSL2 Ubuntu 終端機
# 安裝 Ollama curl -fsSL https://ollama.com/install.sh | sh # 下載推薦的模型（擇一） ollama pull qwen2.5:14b # 平衡品質與速度 ollama pull llama3.1:8b # 較低硬體需求 # 在 Hermes 中設定使用 Ollama hermes model

方案 C：OpenRouter（多模型選擇）

  1. 前往 openrouter.ai 註冊帳號
  2. 在帳號設定中建立 API 金鑰
  3. 選擇免費模型即可使用
WSL2 Ubuntu 終端機
echo 'OPENROUTER_API_KEY=你的API金鑰' >> ~/.hermes/.env

🎓 教師與學生應用指南

🧑‍🏫 教師應用情境

Hermes Agent 可以成為教師的全方位教學助手，以下是幾個實際應用場景：

📝 教案與講義製作

利用記憶系統記住你的教學風格與課綱要求，自動產生符合課綱的教案大綱、學習單、講義內容。

  • 指定科目與章節即可產生結構化教案
  • 自動搜尋最新資料補充教學內容
  • 輸出 Markdown 格式方便匯入各種平台
📊 考題生成與管理

建立「出題技能」，指定難度、題型與章節範圍，批次產生試題並自動分類歸檔。

  • 支援選擇題、填充題、問答題等多種題型
  • 自動依章節歸檔至本機資料夾
  • 可串接題庫資料進行去重與難度校準
🔬 教學素材蒐集

利用瀏覽器自動化功能，批次搜尋並下載教學所需的圖片、影片連結、學術資料。

  • 自動擷取網頁內容並轉為筆記格式
  • 整理研究論文摘要供教學參考
  • 建立個人教學資源知識庫
📁 行政事務自動化

自動化重複性的行政工作：整理成績、格式化報告、批次處理文件檔案。

  • CSV / Excel 資料整理與統計
  • 批次重新命名與歸檔文件
  • 排程定期執行例行任務

🧑‍🎓 學生應用情境

學生可以將 Hermes Agent 當作個人的「知識管理大腦」，打造專屬的學習助手：

🧠 個人知識管理

Hermes 會記住你正在學習的科目、進度與弱點，提供個人化的學習建議與複習計畫。

  • 跨科目整合學習筆記
  • 自動建立知識圖譜與連結
  • 定期提醒複習遺忘曲線上的知識點
📚 課後複習與自學

向 Hermes 提問課堂上不理解的內容，它會根據你的程度用最適合的方式解說。

  • 記住你之前學過的概念避免重複解釋
  • 自動產生練習題檢驗理解程度
  • 搜尋補充資料拓展學習深度
📝 報告與專題製作

協助蒐集資料、整理大綱、生成初稿，加速專題報告的製作流程。

  • 網路資料搜尋與來源整理
  • 協助架構大綱與撰寫段落
  • 自動產生參考文獻格式
💻 程式學習輔助

學習程式設計時，Hermes 可以即時解釋程式碼、協助除錯、建議改進方向。

  • 記住你的程式學習進度
  • 直接在本機執行程式碼驗證結果
  • 循序漸進的教學風格

🔐 隱私與安全提醒

  • Hermes Agent 的所有資料（記憶、技能、對話記錄）完全儲存在你的本機電腦，不會上傳到雲端
  • 使用雲端 API（如 Google AI Studio）時，對話內容會傳送到對應的 AI 服務進行處理，但不會被存取或用於訓練
  • 使用 Ollama 本機模型搭配時，可實現 100% 完全離線運行，適合處理機敏資料
  • 建議不要將個人敏感資訊（身分證字號、密碼等）提供給任何 AI 工具
💡

持續學習的 AI 助手

🐾 AI 終端機助理

OpenClaw 安裝與使用指南

在 Windows 系統上輕鬆部署您的終端機 AI 助理，讓它幫助您自動化操作、撰寫程式與管理檔案。

💻 準備 WSL 環境

為了獲得最佳的相容性與開發體驗，我們強烈建議在 Windows Subsystem for Linux (WSL) 環境中安裝 OpenClaw。請開啟 PowerShell（以系統管理員身分執行），依序輸入以下指令：

  1. 安裝 WSL：
    wsl --install
  2. 更新 WSL 核心：
    wsl --update
  3. 確認安裝狀態：
    wsl -l -v
  4. 設定 Ubuntu 為預設啟動：若您有安裝多個發行版，請確保 Ubuntu 是預設的。
    wsl --set-default Ubuntu

完成後，請重新啟動電腦並開啟 Ubuntu 終端機進行後續操作。

🚀 WSL (Linux) 一鍵安裝

在您的 Ubuntu 終端機中，直接執行以下指令即可進行一鍵安裝，腳本會自動為您配置好 Node.js 等必要環境：

curl -fsSL https://openclaw.ai/install.sh | bash

安裝完成後，輸入 openclaw 即可啟動並進入初始設定。

🔑 取得與設定 API 金鑰

OpenClaw 需要 AI 模型 API 才能運作。本指南推薦使用 Google 的 Gemini 3.1 Flash Lite，它具有極快的反應速度與優異的成本效益：

  1. 前往 Google AI Studio 並登入您的 Google 帳號。
  2. 點擊左側選單的 "Get API key"。
  3. 點選 "Create API key"，並將生成的字串複製下來。
  4. 在 OpenClaw 初始設定或其 .env 設定檔中，選擇 Gemini 作為提供者，並貼上此 API 金鑰。

▶️ 啟動與進行對話

設定完畢後，您只需在終端機輸入啟動指令即可開始與您的 AI 助理對話：

  1. 啟動 OpenClaw：在 Ubuntu 終端機中輸入 openclaw 並按下 Enter，即可進入互動對話模式。
  2. 與 AI 溝通：您可以直接輸入自然語言（繁體中文）指令。例如：幫我建立一個名為 project 的資料夾，並在裡面建立 index.html，AI 會自動分析並在取得您的同意後執行相應的系統指令。
  3. 結束對話：輸入 exit 或按下 Ctrl + C 即可退出。

提示：若遇到終端機錯誤，您可以將錯誤訊息直接貼給 OpenClaw，請它為您分析並自動修復。

💬 LINE 遠端連線設定

您可以將 OpenClaw 與 LINE Bot 結合，實現出門在外也能遠端指揮家裡或學校電腦的操作：

  1. 至 LINE Developers Console 建立一個新的 Provider 與 Messaging API Channel。
  2. 在 Channel 設定中取得 Channel Secret 與 Channel Access Token。
  3. 在 OpenClaw 的設定檔（通常在 ~/.openclaw/config.json 或透過終端機設定介面）中，啟用 LINE 整合，填入上述兩個金鑰。
  4. 使用 ngrok 或其他反向代理工具，將您本機的 OpenClaw webhook port 暴露到網際網路。
  5. 將生成的 HTTPS 網址填回 LINE Developers 的 Webhook URL 欄位並驗證。
  6. 完成後，您就可以在 LINE 官方帳號上傳送文字指令，OpenClaw 將在您的電腦上遠端執行任務並回報結果！

💡 教師與學生應用情境

👨‍🏫 教師應用情境

  • 自動化批改與檔案整理：「幫我把目前資料夾所有學生的作業壓縮檔解壓縮，並依照學號建立獨立資料夾分類。」
  • 教材快速生成：「建立一個 Python 基礎教學的 Markdown 檔案大綱，包含變數、迴圈與函式的範例程式碼。」
  • 遠端管理設備（搭配 LINE）：離開教室時，透過手機 LINE 傳送指令：「關閉電腦所有的瀏覽器視窗，並讓電腦在 5 分鐘後休眠。」

👩‍🎓 學生應用情境

  • 程式除錯小幫手：「我的 Node.js 專案一直報錯說 port 3000 被佔用，幫我找出佔用的程式並關閉它。」
  • 專案環境快速建立：「幫我建立一個包含 HTML, CSS, JavaScript 檔案的基本網頁專案結構，並幫我寫好簡單的導覽列樣板。」
  • Git 版本控制輔助：「幫我把現在的修改建立一個 commit，訊息寫『完成登入頁面排版』，並推送到 GitHub 上。」

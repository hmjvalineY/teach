OpenClaw 安裝與使用指南

在 Windows 系統上輕鬆部署您的終端機 AI 助理，讓它幫助您自動化操作、撰寫程式與管理檔案。

🚀 Windows 一鍵安裝

在 Windows 上，您可以透過 PowerShell 輕鬆進行一鍵安裝。請開啟 PowerShell（建議以系統管理員身分執行），然後輸入以下指令：

powershell -c "irm https://openclaw.ai/install.ps1 | iex"

這個指令會自動下載並執行安裝腳本，為您配置好基本環境。

📦 依賴項目 (Dependencies)

在安裝與運行 OpenClaw 之前，您的系統需要具備以下軟體依賴：

  • Node.js: 必須安裝版本 22 或以上（建議 24）。若版本過舊會導致功能無法正常執行或出錯。
  • Git: 用於管理核心檔案與後續的版本更新。
  • 命令列工具: 需要 PowerShell 或 Windows Terminal 來執行指令及操作介面。

⚙️ 系統運行方式

OpenClaw 在 Windows 上的運行方式主要分為兩種：

  1. Windows 原生 PowerShell 運行： 透過上述的一鍵安裝指令，OpenClaw 會直接在 Windows 的環境中透過 Node.js 執行。這是最直接的方法，但依賴 Windows 的檔案系統與權限機制。
  2. WSL2 運行（推薦）： 開發者社群通常更推薦在 Windows Subsystem for Linux (WSL2) 中運行。它提供更穩定的 Linux 環境，對於許多開發工具、檔案權限和相依套件的相容性更好。

🔧 初始化設定

安裝完成後，您需要進行初始化設定才能開始使用。最重要的是配置 AI 模型的 API 金鑰：

  1. OpenClaw 本身不包含內建模型，您需要提供支援的 API 金鑰，例如 Anthropic Claude 或 OpenAI GPT。
  2. 如果您想使用本地端免費運行的模型，可以搭配 Ollama 使用，只需在設定時指定本地伺服器位址 (例如 http://localhost:11434) 即可。
  3. 首次在終端機啟動 OpenClaw 時，系統會透過互動式選單引導您填入這些資訊，您也可以在生成的設定檔中手動修改環境變數。

💡 如何使用與應用範例

設定完畢後，只需在終端機中輸入 openclaw 即可啟動您的 AI 助理並開始對話。

應用範例 1：建立專案結構

您可以直接用語音或文字命令它：

"請幫我建立一個名為 my-react-app 的 React 專案，並安裝 tailwindcss。"

OpenClaw 會自動分析指令，並在終端機中為您產生並執行 npx create-react-app 及相關設定指令。

應用範例 2：檔案管理與整理

"把目前資料夾中所有的 .jpg 圖片移動到名為 Images 的新資料夾中。"

它會讀取當前目錄的檔案列表，自動建立資料夾並執行搬移操作，免去手動輸入複雜 PowerShell 指令的麻煩。

應用範例 3：系統疑難排解

"我的 8080 port 被哪個處理程序佔用了？請幫我找出來並關閉它。"

它會自動執行系統網路指令（如 netstat 或 Get-Process），找出佔用該 port 的程式並在取得您的確認後終止該程序。
